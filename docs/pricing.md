# Perpendicular pricing

## Open Source — free forever

Self-host Perpendicular on the Dell or another Linux host. You provide the machine, storage, backups, model runtime, and any provider credentials you choose to connect. The product itself has no per-seat fee, hosted-model fee, or mandatory vendor subscription.

The product exposes this plan at `/api/pricing`. There is intentionally no Stripe checkout in the current launch because a UI plan toggle is not billing. Paid hosted plans can be added later only with real price IDs, webhook verification, entitlement storage, refunds, and a support policy.
